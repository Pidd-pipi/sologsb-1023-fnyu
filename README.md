# 校异斋 · 多版本文本自动比对与人工校勘工具

面向古籍和长文本编辑的多版本校勘工作台。可导入同一作品的不同版本，自动按段落与句子对齐，再由人工修正错位、判断增删改并导出校勘记。

## 功能

- 导入或粘贴同一作品的不同版本，按空行分段，再按句末标点切句。
- 自动对齐按 24 个句段一组让出浏览器主线程，长文本处理期间持续显示进度。
- 比较规则可忽略标点或常见异体字；规则变化会重算相同、改动和疑错位状态，不改写原文。
- 人工可交换邻近底本句的配对关系、整行移动、手动标记相同/改动/新增/删减/误错位。
- 每条差异可填写校勘说明和来源，并可勾选后批量接受或一键接受全部建议。
- 支持跳转到下一处未接受差异，以及键盘操作：`Alt+↓` 下一处、`A` 接受勾选、`Ctrl/⌘+Z` 撤销、`Ctrl/⌘+Y` 或 `Ctrl/⌘+Shift+Z` 重做。
- 最多保留 50 步撤销历史，版本、规则、对齐行、校记和当前位置自动保存在 `localStorage`。
- 双页签离线接力：同一时刻仅持锁页签可写，1.5 秒心跳、8 秒超时；写入页签崩溃后心跳停止，其他页签可接回锁内草稿接管写入，也可主动停止心跳让出写入权。
- 非写入页签编辑时自动分叉为离线草稿（含分叉底稿）；写入权空出后一键三路合并，双方各改各行自动并入。
- 双方改过同一对齐行时，各自的判断、校勘说明和来源都保留并列入「待裁决」；裁决完成前对应行不能接受、整份校勘记也不能导出。
- 比较规则一旦改变，原已接受的校勘记录立即失效（取消接受）并重算：人工挪动与人工判断保留并标记「待复核」，原文始终不动。
- 合并前做容量预检并分阶段写入主稿与锁草稿；本地容量不足时拒绝合并并回滚，线上原稿与离线原稿都不变。
- 导出 Markdown 校勘记或完整 JSON 校勘数据（含待裁决记录）。
- 桌面三栏工作区，窄屏自动堆叠；提供读屏可识别的表头、标签、状态与按钮名称。

## 多页签接力说明

- 打开的第一个页签自动取得写入权；其他页签为只读，会实时同步主稿。
- 在只读页签上直接编辑即自动转为「离线编辑」：改动保存在该页签独立的 stash 中，不影响正在写入的页签。
- 写入页签关闭（正常退出会立即释放锁）或崩溃后，离线页签点击「合并离线改动」；若检测到崩溃草稿，优先接回崩溃前未入主稿的内容再合并。
- 崩溃在离线编辑中途发生也不会丢稿：该页签重开时自动恢复自己的 stash；其他页签取得写入权后还能在状态栏看到并代为合并遗留草稿。
- 待裁决冲突需逐条选择采用哪一方的判断；裁决后该行转为「待复核」，核对后才能重新接受。

## 测试

纯逻辑（三路合并、规则失效、锁协议、容量回滚）不依赖浏览器，使用 esbuild 临时打包后在 Node 中断言：

```bash
npm test
```

## 技术栈

- Vue 3 + Vite + TypeScript
- Arco Design Vue 2
- 浏览器 localStorage
- 无后端服务，全部计算在浏览器本地执行

## 本地开发

```bash
npm install
npm run dev
```

打开终端显示的 Vite 地址。源码未硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
```

类型检查和生产产物会生成到 `dist/`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1023 .
docker run --rm -p 10023:80 sologsb-1023
```

容器内 nginx 监听 `80`，根据根端口表映射到宿主 `10023`。

## 数据说明

版本正文、对齐结果、校勘说明和撤销记录均保存在当前浏览器。清除站点数据会删除草稿，建议定期导出 JSON 或 Markdown 校勘记。
